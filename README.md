# Lyricism

Animated, synced lyrics for whatever you're playing on Spotify — iMessage, Poster, Stars, Orbit, Lock Screen and Widgets styles.

Open the site, press **Connect Spotify**, and play something. Your Spotify account must be added to the app's allowed users by the owner.

Credits: lyrics from [LRCLIB](https://lrclib.net); planet maps from [Solar System Scope](https://www.solarsystemscope.com/textures/) (CC BY 4.0) via Wikimedia Commons.
